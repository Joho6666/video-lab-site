# Video Lab · 个人服务介绍网站

介绍 **AI 复刻视频** 与 **AI 智能剪辑** 两项服务的单页网站：深色影院风、纯静态（HTML + CSS + 原生 JS，零依赖）。

页面内容：首屏冲击力背景、两项服务、工作流程、四条原创样片、保障与成本、合规边界、常见问题、预约演示表单（占位）。

## 本地预览

```bash
node server.mjs        # http://localhost:3400
```

## 部署

纯静态站，可直接拖拽整个文件夹到 Netlify Drop，或使用 GitHub Pages / Cloudflare Pages / Vercel。

## 说明

- `media/` 里的样片均为 **AI 原创生成**（虚构品牌、原创角色，画面内无文字与商标）。
- 预约表单仅在浏览器内校验，**不会发送任何数据**；上线前请接入真实的预约渠道，并替换页面中的占位品牌名 “Joho · Video Lab”。
- 本仓库不包含任何第三方作品、客户项目素材或真人肖像素材。
